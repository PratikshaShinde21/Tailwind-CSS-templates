
# Tailwind CSS Templates

A collection of simple, modern, and attractive web page templates created using HTML and Tailwind CSS.

## About the Project

This project includes different website templates designed to practice frontend development and improve UI design skills.

## Technologies Used

- HTML5
- Tailwind CSS

## Features

- Clean and modern UI
- Responsive layouts
- Attractive designs
- Simple and reusable code
- Beginner-friendly templates

## Templates Included

- Landing Page
- Dashboard UI
- Movie Cards
- Pricing Page
- Other Web Page Designs

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open any HTML file in your browser.

## What I Learned

- Using Tailwind CSS utility classes
- Creating layouts with Flexbox
- Working with colors, spacing, and typography
- Designing attractive web pages
